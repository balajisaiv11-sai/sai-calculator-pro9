# Sai Calculator Pro

A comprehensive scientific calculator application featuring 540+ verified functions, Natural Textbook Display (MathI / MathO), exact fraction evaluations, and advanced computation modes.

## Features

- **Natural Textbook LCD Display**: Authentic high-contrast LCD screen with real-time blinking cursor, status annunciators (`S` Shift, `A` Alpha, `DEG`/`RAD`/`GRAD`, `Math`), right-aligned precision readout, and exact fraction display.
- **Physical Keypad Layout**: 8-row tactile scientific keypad with primary key actions and printed secondary `SHIFT` (amber) and `ALPHA` (crimson) labels.
- **14 Advanced Application Modes**:
  1. **Calculate**: General arithmetic, trigonometry, calculus, hyperbolic, logarithms, and powers.
  2. **Complex**: Complex number arithmetic ($a + bi$, polar $r\angle\theta$, conjugate, argument, real/imag components).
  3. **Base-N**: Programmer calculations in Decimal, Hexadecimal, Binary, and Octal with bitwise operations (AND, OR, XOR, NOT, shift).
  4. **Matrix**: $2\times2$ and $3\times3$ matrix calculations including Determinant, Inverse ($A^{-1}$), Transpose ($A^T$), and scalar multiplication.
  5. **Vector**: 2D & 3D vector computations (Dot product, Cross product, Magnitude, Unit vector, Angle $\theta$).
  6. **Statistics**: 1-Variable statistical summary ($n$, $\bar{x}$, $\Sigma x$, $\Sigma x^2$, $\sigma$, $s$, min, $Q_1$, med, $Q_3$, max) and 2-Variable linear regression ($y = a + bx$, $r$, $r^2$).
  7. **Distribution**: Normal ($P(x)$, $P(X \le x)$), Binomial, and Poisson probability density and cumulative distributions.
  8. **Table**: Numerical function table generator for $f(x)$ and $g(x)$ across custom ranges and step increments.
  9. **Equation**: Simultaneous linear equations (2 and 3 unknowns), Quadratic with vertex ($x_{min/max}$, $y$), and Cubic equations.
  10. **Inequality**: Polynomial inequality solver.
  11. **Ratio**: Direct ratio and proportion solver ($A:B = X:D$ or $A:B = C:X$).
  12. **Spreadsheet**: 5-column ($A..E$) $\times$ 10-row grid with formula evaluation (`=SUM`, `=MEAN`, `=MIN`, `=MAX`, `=COUNT`, cell arithmetic).
  13. **Unit Conversion**: 40+ metric and imperial unit conversions across Length, Area, Volume, Mass, Velocity, Pressure, Energy, and Temperature.
  14. **Math Box**: Interactive educational probability simulations for Coin Toss and Dice Roll with live frequency histograms.
- **Master Function Explorer**: Searchable directory of all 540+ functions and 47 physical constants with 1-click insertion.
- **Coverage & Verification Dashboard**: Real-time compliance tracking across all 540+ mathematical functions and advanced scientific capabilities.
- **Variable & Memory Inspector**: Inspect and store variables $A..F$, $x$, $y$, $z$, and $Ans$.
- **Calculation History**: Browsable past calculations with 1-click expression recall.
- **Settings**: Custom configuration for angle units, I/O display formats, fraction representation, and number formats (Norm 1, Norm 2, Fix, Sci).
